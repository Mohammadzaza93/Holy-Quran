# خادم الفحص المتقدم للحركات (اختياري)

يشغّل نموذج [quran-muaalem](https://github.com/obadx/quran-muaalem) (رخصة MIT) ليستعمله التطبيق
في شاشة «فحص متقدم للحركات». التطبيق يعمل كاملاً بدونه.

> **تنبيه:** لم يُشغَّل هذا الخادم ولم يُختبر مع التطبيق من بيئة التطوير (لا وصول إلى Hugging Face ولا معالج رسومي).
> جرّبه على جهازك وأبلغ بما يظهر. دقة النموذج في أحكام التجويد نحو ٧٦٪، فنتائجه «اشتباه» لا حكم.

## المتطلبات
- Python 3.10+، ومساحة نحو ٣ جيجابايت للنموذج (٦٦٠ مليون معامل).
- معالج رسومي يُسرّع كثيراً؛ على المعالج العادي يستغرق التحليل عدة ثوانٍ.
- أن يصل الهاتف إلى الخادم (نفس الشبكة، أو نفق مثل `cloudflared`/`ngrok`).

## التشغيل
```bash
bash server/run.sh
```
يشغّل عمليتين: المحرّك (منفذ 8000) والتطبيق (منفذ 8001). ثم أدخل في التطبيق:
`http://عنوان-جهازك:8001` واضغط «اختبار».

## واجهة الخادم
`POST /correct-recitation` (multipart): الحقل `file` (WAV). يعيد `uthmani_text` و`errors`
(نوعها `tashkeel` للحركات، `tajweed`، `normal`)، أو 404 إن لم تُطابق آية.

## استضافة مجانية على Google Colab (موصى بها)
> Hugging Face Spaces لم تعد تدعم Docker مجاناً (يحتاج اشتراكاً).
1. افتح `server/colab.ipynb` في colab.research.google.com (File ← Upload، أو من GitHub).
2. فعّل GPU: Runtime ← Change runtime type ← T4.
3. شغّل الخلايا بالترتيب (الأولى ثقيلة: نحو 5-10 دقائق مع تنزيل النموذج).
4. انسخ رابط `trycloudflare.com` الذي يظهر وضعه في التطبيق ثم «اختبار».
- مؤقت: يتوقف عند الخمول وتتغيّر الرابط في كل تشغيل. الرابط عام لمن يعرفه.
