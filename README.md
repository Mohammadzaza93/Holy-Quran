# تجويد حفص — اختبار وتسميع

![Flutter](https://img.shields.io/badge/Flutter-02569B?logo=flutter&logoColor=white)
![Platform](https://img.shields.io/badge/Platform-Android%20%7C%20iOS-blue)

تطبيق Flutter لمراجعة **أحكام التجويد برواية حفص**، مع اختبارات، تسميع بالتعرف الصوتي، وشرح مرئي من سلسلة الشيخ أيمن رشدي سويد.

**حر · بدون إعلانات منّا · بيانات محلية على الجهاز** — انظر [سياسة الخصوصية](PRIVACY.md).

## المميزات

- بنك أسئلة تجويد (رواية حفص)
- اقرأ وصحّح تلاوتك: مقارنة كلمة بكلمة مع تتبع حي
- شرح التجويد المصور: 45 حلقة على يوتيوب للشيخ أيمن سويد
- يعمل جزء كبير منه بدون إنترنت بعد تحميل نص المصحف
- وضع إتقان وتقرير ضعف الحفظ

## حدود التعرف الصوتي

- يعتمد على محرك الجهاز (Google / Apple)
- يكشف: كلمة مبدّلة، متروكة، زائدة
- لا يكشف المدود والغنة والمخارج بدقة — ليس بديلاً عن المقرئ

### إن ظهرت رسالة العربية غير مفعّلة

على أندرويد (خصوصاً شاومي):

1. ثبّت/حدّث تطبيق Google
2. الإعدادات ← التطبيقات ← Google ← أذونات ← الميكروفون
3. الإعدادات ← النظام ← اللغات ← أضف العربية
4. إعدادات Google ← الصوت ← التعرف دون اتصال ← حمّل العربية
5. في التطبيق: الإعدادات ← جرّب تفعيل/تعطيل «التعرف على الجهاز»
